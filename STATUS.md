# STATUS

Free AI Image Tools Directory — Asdale Dynamics, LLC

## What was built

A free, no-account-required directory of AI image generators and tools,
delivered as Markdown plus a printable HTML version, in
`/workspace/kilo-lab/free-ai-image-tools-directory`.

Files:
- `README.md` — the directory in Markdown: browser-based tools (Craiyon,
  Pollinations, Hugging Face Spaces), local tools (Automatic1111 Stable
  Diffusion WebUI, ComfyUI, Fooocus, DiffusionBee, InvokeAI), open-source
  models/weights (SD 1.5/2.1/XL, Flux.1 schnell/dev), usage limits, privacy
  notes, three step-by-step beginner tutorials, a "choosing the right tool"
  guide, license/credit, and a disclaimer.
- `free-ai-image-tools.html` — printable HTML generated from `README.md`
  (A4 page size, print styles, clickable links shown as URLs when printed).
- `generate-html.py` — standard-library Python script that builds the HTML
  from the Markdown. Run: `python3 generate-html.py README.md free-ai-image-tools.html`
- `test_build.py` — test suite that rebuilds the HTML and validates structure,
  required content, and absence of secrets/personal data.
- `LICENSE` — MIT License, copyright line exactly
  `Copyright (c) 2026 Asdale Dynamics, LLC`.
- `STATUS.md` — this file.

## How to run it

Read `README.md` directly in any Markdown viewer or text editor.

To regenerate the printable HTML:

```
python3 generate-html.py README.md free-ai-image-tools.html
```

Requires only Python 3 (standard library). Open `free-ai-image-tools.html` in
a browser, or print to PDF from the browser's print dialog (A4 styles apply
automatically).

To run the test suite:

```
python3 test_build.py
```

Known gaps
- HTML is generated by a small custom Markdown converter, not a full Markdown
  engine; it handles the subset used by `README.md` (headings, bold, links,
  inline code, fenced code blocks, ordered/unordered lists, tables, horizontal
  rules). Re-run `generate-html.py` after editing `README.md`.
- Tool details (usage limits, pricing, privacy practices) change over time;
  verify on each tool's website before relying on them.
- Civitai is mentioned as a model source but requires an account for downloads,
  so it is not featured as a no-account option.
- Local tools perform best with an NVIDIA GPU; CPU-only operation is slow.
- No automated test runner/CI workflow (intentionally: no `.github/workflows`
  per requirements); `test_build.py` is run manually.
- This directory is educational only, not medical, legal, or financial advice.
