## What was built

A free, no-account-required directory of AI image generators and tools, delivered as Markdown plus a printable HTML version, in `/workspace/kilo-lab/free-ai-image-tools-directory`.

Files:
- `README.md` — the directory in Markdown: browser-based tools (Craiyon, Pollinations, Hugging Face Spaces), local tools (Automatic1111 Stable Diffusion WebUI, ComfyUI, Fooocus, DiffusionBee, InvokeAI), open-source models/weights (SD 1.5/2.1/XL, Flux.1 schnell/dev), usage limits, privacy notes, three step-by-step beginner tutorials, a "choosing the right tool" guide, license/credit, and a disclaimer.

- `generate-html.py` — standard-library Python script that builds the HTML from the Markdown. Run: `python3 generate-html.py README.md free-ai-image-tools.html`

## How to run it

Read `README.md` directly in any Markdown viewer or text editor.

To regenerate the printable HTML:

```
python3 generate-html.py README.md free-ai-image-tools.html
```

Requires only Python 3 (standard library). Open `free-ai-image-tools.html` in a browser, or print to PDF from the browser's print dialog (A4 styles apply automatically).

- Tool details (usage limits, pricing, privacy practices) change over time; verify on each tool's website before relying on them.
- Civitai is mentioned as a model source but requires an account for downloads, so it is not listed as a no-account tool.
- No automated test suite or CI workflow (intentionally: no `.github/workflows` per requirements).
